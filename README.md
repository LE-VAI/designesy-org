# Designesy

Design intelligence infrastructure for better worlds.

Designesy turns sources into principles, principles into contracts, and contracts into tools, systems, and artifacts that improve quality of life.

This repository is the controlled public root for Designesy.

It is governed by:

- `DESIGN.md` — the design contract
- `AGENTS.md` — agent operating rules
- `docs/designesy` — context, architecture, logs, and registries

Designesy is not a template gallery.
Designesy is not a generic AI design tool.
Designesy is not a moodboard.

Designesy is a system.

## Status

Private foundation stage. Public deployment pending.
